## 一句话 / One line

**SACAL 1.0 = 自定义源可用许可证**：
无限商用、无托管限制、**仅强制署名**。
不是 OSI 开源，不属于 Creative Commons 体系。

**SACAL 1.0** = a custom source-available licence:
commercial use allowed, no hosting restriction, **attribution only**.
Not OSI-approved open source; not part of Creative Commons.

## 快速开始 / Quick start

1. **每个作品一个目录**，目录名即作品名。
   One directory per work; the directory name **is** the work name.
2. 在该作品旁放一份 `LICENSE`，把开头的「**作品名 / 作者名**」改成**该作品自己的**。
   Place `LICENSE` next to the work; change **Work name / Author** above to **that work's own**.
3. 在界面显示一行：
   Display one line in the UI:

   ```
   Powered by <作品名>（<作者名>）
   Project URL: <网址>          ← 可选 / optional
   ```

> 没有网址不构成免除署名的理由。
> Absence of a URL does NOT excuse the attribution obligation.

## 署名规则 / Attribution

- 每个作品须标示 **(a) 作品名** + **(b) 作者**，**两项独立、不得合并或替换**。
  Each work must identify **(a) work name** + **(b) author**, kept separate.
- **作者自己署名**；代发方（ST工作室）不代填、不替代。
  The **author** fills it in. The distributor (ST Studio) does NOT.
- ST工作室只出现在独立的「**发布者 / Published by**」位置。
  ST Studio appears only at a separate "Published by" line.

详见 LICENSE「二、署名义务 / Attribution Requirement」。
